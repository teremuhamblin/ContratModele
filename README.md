# ContratModele
### 📄 Contrats pour freelances informatiques

Ce dépôt centralise des *modèles de contrats pour les développeurs*, **consultants et freelances IT**.
- Ces documents circulent gratuitement sur le web, mais sont parfois difficiles à trouver : l'objectif ici est de les regrouper au même endroit au format Markdown pour qu'ils soient faciles à consulter, copier et adapter.

---

## ⭐ Le modèle recommandé pour les indépendants

Si vous êtes freelance et démarrez une mission chez un client (ou via un intermédiaire), le modèle le plus adapté à votre situation est :

👉 **[assistance-technique-freelance.md](DOCS/assistance-technique-freelance.md)**

## 🛠️ Comment utiliser ces modèles ?

1. Choisissez le fichier correspondant à votre besoin et copiez son contenu (ou téléchargez le dépôt).

2. Remplacez les champs génériques (noms des sociétés, SIRET, tarifs, dates, périmètre de la mission, etc.).

3. Relisez attentivement chaque clause pour l'adapter à votre accord commercial.

4. Exportez le document final en **PDF** (via VS Code, Pandoc, Typora ou un outil en ligne) avant de l'envoyer pour signature.

---

## ⚠️ Avertissement juridique

> Les modèles présents dans ce dépôt sont fournis **à titre purement informatif**. Ils ne constituent en aucun cas un conseil juridique. La législation évoluant régulièrement (RGPD, propriété intellectuelle, statut juridique, etc.), il est vivement recommandé de faire relire vos contrats par un professionnel du droit (avocat ou juriste) avant toute signature.
